# Title: update-changelog
# Description: Add a correct entry to CHANGELOG.md for the change just made.

Step 1: Open `CHANGELOG.md` and find `## [Unreleased]`.

Step 2: Choose the category (Added, Changed, Deprecated, Removed, Fixed,
Security, Breaking, Decisions, Docs).

Step 3: Write one plain-language line with the requirement or phase id.

Step 4: For an answered OWNER DECISION, add the row to `docs/decisions.md`
too.

Step 5: Re-read the line: no secrets, no passwords, no tokens.
